# Optional 3D model assets

The renderer is self-contained and does not require external 3D models to run.
This folder is reserved for optional high-fidelity Earth/Sun/spacecraft meshes.

Recommended sources:
- NASA 3D Resources: https://www.nasa.gov/3d-resources/
- NASA Science Earth 3D model: https://science.nasa.gov/resource/earth-3d-model/

Do not distribute third-party model files unless their licenses permit redistribution.
